# NEXUS visual assets

These original vector assets are authored for NEXUS OS:

- `nexus-logo.svg` is the NEXUS geometric N mark.
- `nexus-wallpaper.svg` is the default dark workstation wallpaper.

The live ISO build installs the mark under `/usr/share/pixmaps` and configures the wallpaper as the XFCE default. They contain no remote resources, scripts, or tracking pixels.
